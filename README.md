# Worldbuilder language packs

The UI texts of the [Worldbuilder](https://vizinet.dev) app, one file per language: `{"English text": "translation"}`.
The app is built with English only and downloads the language it needs from here.

Only texts of the app's screens are here: no code, no user data. Counted nouns (`#place`) hold the forms the
language needs, separated by `|`. Placeholders like `{name}` stay as they are.

Found a mistake? Write to support@vizinet.dev.
